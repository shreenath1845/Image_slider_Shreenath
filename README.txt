# Image Slider Project

This project is an interactive image slider created using HTML, CSS, and JavaScript. It includes:
- A responsive design.
- Navigation buttons (Next and Previous).
- An automatic slideshow feature.
- Smooth transitions between images.

## How to Run:
1. Open `index.html` in any modern web browser.
2. Use the "Next" and "Previous" buttons to navigate through the images.
3. The slider will automatically transition every 3 seconds.
